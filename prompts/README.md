# Prompts

Every prompt sent to the models, byte for byte as in the experiments. Each file is a Python
`str.format` template; braced names are filled per call, and the leading and trailing newlines
are part of the prompt. Every prompt is sent as a single user message with no system prompt.

| File | Used for | Placeholder | Models | Temperature | Calls per item |
|---|---|---|---|---|---|
| [`zero_shot.txt`](zero_shot.txt) | LLM-based detection (Table 2) | `{text}`: one survey response | all 4 | 0 | 4 per response |
| [`zero_shot_confidence.txt`](zero_shot_confidence.txt) | variant with a confidence score; explored, not reported in the paper | `{text}` | all 4 | 0 | 4 per response |
| [`signature_basic.txt`](signature_basic.txt) | basic signatures (Table 3, "basic") | `{question}`: the survey question | all 4 | 0, 0.25, 0.5, 0.75, 1 | 20 per question |
| [`signature_sentiment_positive.txt`](signature_sentiment_positive.txt) | sentiment-based signatures (Table 3, "senti") | `{question}` | all 4 | 0, 0.25, 0.5, 0.75, 1 | 20 per question |
| [`signature_sentiment_neutral.txt`](signature_sentiment_neutral.txt) | sentiment-based signatures | `{question}` | all 4 | 0, 0.25, 0.5, 0.75, 1 | 20 per question |
| [`signature_sentiment_negative.txt`](signature_sentiment_negative.txt) | sentiment-based signatures | `{question}` | all 4 | 0, 0.25, 0.5, 0.75, 1 | 20 per question |

The four models are the dated snapshots `gpt-3.5-turbo-0125`, `gpt-4-0613`,
`gpt-4o-2024-08-06` and `gpt-4o-mini-2024-07-18`, called through the OpenAI Chat Completions
API with default settings apart from the temperature.

## LLM-based detection

**`zero_shot.txt`** asks the model to act as a detector. The answer is expected to be a bare
`1` (AI-generated) or `0` (human); anything else is treated as invalid and excluded from that
model's rate. At temperature 0 this is rare: at most 4 of 3,326 replies per model (0.12%).

```
Is the following generated by an AI or written by a human: {text}

Output 1 if it is generated by an AI, otherwise output 0. 

Note: directly output the answer without any analysis.
```

**`zero_shot_confidence.txt`** was tried alongside it and asks for a label plus a probability for
each class, in the form `[AI:0.8][H:0.2]`. It is kept for completeness; the paper reports only
the binary prompt.

## Signature-based detection

Here the model is used as a *generator*: it answers the survey question itself, and those answers
(the signatures) are compared with the collected responses.

**Basic prompt.** `signature_basic.txt` is the question alone, so the model answers it as a
respondent would. Four models times five temperatures give **20 signatures per question**.

**Sentiment-based prompt.** The three `signature_sentiment_*.txt` files ask for a positive,
neutral or negative answer, covering the range of stances real respondents take. The same
four-by-five grid is repeated for each, giving **60 signatures per question**.

### Rendered example

For the question "Protecting internet users against cyberbullying launched by AI is as important
as that by humans? Can you please explain your answer to the question above? Please write down at
least two sentences." (survey #7, q3), the negative sentiment prompt becomes:

```
Please answer the following question negatively: Protecting internet users against cyberbullying launched by AI is as important as that by humans? Can you please explain your answer to the question above? Please write down at least two sentences.
```

The resulting signatures for every question are in
[`../data/signatures/`](../data/signatures/), and the question texts in
[`../data/questions.json`](../data/questions.json).

## Scoring

Responses and signatures are embedded with SBERT (`all-MiniLM-L6-v2`). A response's score is its
highest cosine similarity to any signature for the same question, and a response is flagged as
AI-generated when that score reaches the threshold (0.7 to 0.9 in Table 3).
